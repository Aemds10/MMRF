# Projet de Stage " Machine Learning pour l'analyse du Myelome Multiple " - Laboratoire COMET

#### Lien vers page html : aemds10.github.io/Stage---MMRF/dashboard_MMRF.html    

Ce dépôt contient les fichiers développés dans le cadre de mon stage au laboratoire COMET (Communication Cellulaire et Microenvironnement Tumoral), rattaché à l’Université de Poitiers.

L’objectif du stage est d’explorer et d’analyser des données RNA-seq issues de la cohorte MMRF (Multiple Myeloma Research Fondation) afin d'identifier les gènes co-régulés avec les 4 gènes d'intérêt étudiés au laboratoire COMET (NTRK2, NTRK3, GJA1, SORT1).

Le travail a également porté sur l'étude des caractéristiques des profils cliniques des patients présentant une forte expression d'un ou des gènes d'intérêt.

Le fichier HTML présent dans ce dépôt permet de visualiser les résultats, les analyses statistiques ou les données expérimentales issues du travail réalisé.
